# Root-cause analysis

## Unnatural composition

The renderer treated graph rank as a sufficient proxy for narrative order. Cycles, convergence, shared terminals, and recovery edges made that proxy unstable. Pagination considered phase membership and capacity but not whether ordinary business steps progressed forward between slides. Candidate selection rewarded feasibility more strongly than primary-journey continuity.

## Supplier-invoice overview regression

The regression came from unbounded effort spent on an unfavorable port and grid combination. The canonical builder now uses deterministic per-candidate limits, fewer port pairs for new process-map candidates, and an endpoint-safe orthogonal fallback. The 22-node supplier overview renders in 28.741 seconds with complete 22/22 node and 27/27 edge coverage.

## Banking connector crossings

The 34-node banking fixture remains at 26 reported crossings. Contact-sheet inspection confirms that most occur in the dense identity and compliance decision area, where several preserved exception and recovery relationships share limited corridors. Small route-order changes did not reduce the count reliably and sometimes created branch-label association failures. The validation threshold was not weakened. A material improvement requires a later local branch-recomposition change, not a scoring-only adjustment.

## Exact 68-node workflow

The exact operational credit-card graph exhausts the 110-second routing bound. The frozen pre-change builder also fails at the same bound, after 413,546 grid expansions, so this is an existing complexity limitation rather than a main-path regression. The new run fails explicitly, preserves the graph, and writes no partial presentation. Increasing the deadline alone would violate the bounded-search requirement and would not establish acceptable composition quality.
